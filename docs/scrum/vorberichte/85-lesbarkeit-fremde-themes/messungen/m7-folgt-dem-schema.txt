Ein Theme folgt dem Schema nur, wenn es sich MIT dem Schema aendert.
Eine Messung unter EINEM Schema kann das nicht zeigen — sie zeigt nur
Uebereinstimmung, und die kann Zufall sein. Genau der Zufall steht in der
Tabelle des Issues (CachyOS-Nord-round unter dem Nord-Schema).
